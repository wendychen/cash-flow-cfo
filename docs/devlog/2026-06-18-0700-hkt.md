## Architecture

### Engine (`src/lib/goalReachPlanner.ts`)

**Input:** active goals, tasks, `latestSavingsBalance`, `monthlySurplus`, optional `longTermFinGoal`, `horizonMonths` (default 36).

**Output:** `GoalReachPlanSnapshot`

| Field | Purpose |
|-------|---------|
| `feasibility` | 0–100 score |
| `feasibilityBreakdown` | budget 40%, deadline spread 30%, surplus 20%, milestones 10% |
| `goalRows` | per-goal funding need/gap, timeline %, `atRisk`, `earliestFeasibleDeadline` |
| `conflicts` | typed conflicts with i18n `messageKey` + params |
| `monthlyFunding` | greedy surplus assignment by deadline order |
| `weeklyFocus` | tasks/milestones due in 7 days (magic wand first, top 3) |

**Exports:** `computeGoalReachPlan()`, `detectDeadlineClusters()`.

### UI (Goals tab → **Planner**)

```
Dashboard → Goals → [ List | Planner ]
├── GoalReachPlannerCard
│   ├── FeasibilitySummaryChip (+ View conflicts button)
│   ├── WeeklyFocusList
│   ├── savings / funding gap warnings
│   ├── GoalMasterTimeline
│   ├── MonthlyFundingChart (12 mo stacked bars)
│   └── PlannerConflictDrawer (sheet, right)
└── Goal Budget Allocator (always below)
```

### Conflict actions (PR-3)

| Conflict | Action |
|----------|--------|
| Over-allocated budgets | Scroll to Budget Allocator |
| Deadline cluster | Suggest +60d shift on latest non-wand goal → **Apply** updates deadline |
| Task cost > budget, funding gap, overdue | Switch to List view, scroll to `#goal-{id}` |

**Utils:** `src/lib/plannerConflictUtils.ts` — format details, cluster shift suggestion.

### i18n

`goalReach.*` in `en.ts`, `zh-TW.ts`, `ja.ts` — feasibility, timeline, weekly focus, conflicts, panel labels.

## How to use (you)

1. **Goals** tab → **Planner**
2. Check **Feasibility** % and **This week** focus items
3. If conflicts exist → **View conflicts (N)** → use action buttons
4. **Refresh** recomputes countdowns
5. **List** view still edits goals; allocator stays under both views
