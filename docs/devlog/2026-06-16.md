# 2026-06-16 — Zustand refactor merged to main

## Summary

Completed the in-flight architecture refactor and merged `direction-1-cutover` into `main`.

## What shipped

- **Zustand store** (`cash-flow-cfo-storage`) with normalized v2 data model (goals + tasks as flat arrays)
- **Cross-domain orchestration** — shadow expenses, bidirectional goal/expense/task sync, cascade deletes, savings ↔ targets
- **Dashboard cutover** — `Index.tsx` now renders `features/dashboard/Dashboard` instead of the 1,710-line `ExpenseTracker`
- **Test suite** — 26 Vitest tests (migration, localStorage re-import, cross-domain invariants, CSV/JSON import)
- **Data portability** — JSON export/import in UI; CLI tools for legacy CSV and localStorage dumps
- **UI fixes** — summary stat cards and Sankey diagram sizing/padding (no horizontal scroll, values stay in cards)
- **Docker** — production image via `compose.yml` (port 8080)

## Lessons

- Build the test/fixture layer before cutting over persistence — migration tests caught several edge cases early.
- Keep one worktree on `main` after merge; feature branches (`direction-6`, `direction-2`) were folded in sequentially.
- Legacy users on per-domain localStorage keys auto-import on first load; CSV export from the old app still works via Import JSON/CSV.
